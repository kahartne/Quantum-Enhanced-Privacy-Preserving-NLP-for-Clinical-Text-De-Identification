# Literature Review

This directory contains the literature reviewed throughout the QuantumHPC DREU project.

- `Literature_Review.xlsx` — Master literature tracking spreadsheet.
- `references.md` — Master IEEE reference list.
- `bibliography.bib` — BibTeX database for reports and publications.
- `notes/` — Detailed notes and summaries for each reference.

Each paper is assigned a unique reference ID (e.g., `001`, `002`) that is used consistently across the spreadsheet, note files, and bibliography.
