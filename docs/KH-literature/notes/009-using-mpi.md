# 009 – Using MPI

## IEEE Reference

[9] W. Gropp, E. Lusk, and A. Skjellum, *Using MPI: Portable Parallel Programming with the Message-Passing Interface*, 3rd ed. Cambridge, MA, USA: MIT Press, 2014.

---

## Purpose

Learn the theory and practical implementation of MPI programming. Helps to gain a deeper understanding of distributed-memory parallel programming before implementing MPI into the QuantumHPC benchmarking framework.

---

## Summary

This textbook introduces MPI fundamentals, including process management, communicators, synchronization, collective communication, parallel algorithms, and scalable software design for distributed-memory systems.

---

## Important Topics

- MPI philosophy
- Distributed-memory computing
- Point-to-point communication
- Collective communication
- Synchronization
- Scalability

- Multi-node execution
