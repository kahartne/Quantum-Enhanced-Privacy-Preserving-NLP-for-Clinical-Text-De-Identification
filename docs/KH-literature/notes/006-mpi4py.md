## Purpose

Official Python bindings for MPI. Useful in understanding how MPI can be integrated into the project's Python framework for distributed benchmarking.

---

## Summary

mpi4py provides Python bindings to MPI, allowing Python programs to perform distributed-memory parallel computing using the MPI standard. It supports point-to-point communication, collective communication, communicators, and parallel execution across multiple processors.
